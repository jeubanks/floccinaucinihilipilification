# Tracker Overview

Use this site as a lightweight public notebook for work in progress.

## How this site is organized

- The **blog** is for short updates, launch notes, and retrospective posts.
- The **tracker docs** hold current status, active projects, and next steps.
- The **archive** can hold finished work once it no longer needs to stay front and center.

## Quick start

1. Write a short blog post when something changes.
2. Update the tracker page when the plan or status changes.
3. Keep the page titles short so the sidebar stays readable.

## Suggested pages

- [Now](./now) for the current focus.
- [Projects](./projects) for the active list.
- The blog index for dated updates.

## Writing rule

Prefer status, decisions, and next actions over long background context.
